关键事件

账户安全

修改密码

使用当前登录密码完成校验后，更新管理员账户密码，并自动使其他会话失效。

安全设置

更新登录密码

新密码至少 6 位。提交成功后，当前会话保留，其他已登录会话会自动失效。 


              


              

                

                  

                    
安全建议

                    
账户使用建议

                  

                

                

                  

                    定期轮换密码
                    建议在共享环境或多人协作场景中，按周期轮换管理员密码。
                  

                  

                    避免重复使用
                    不要与其他平台共用同一密码，降低凭据泄露后的连带风险。
                  

                  

                    修改后重新同步
                    如果其他浏览器标签页仍在使用旧会话，它们会在下次请求时被要求重新登录。

标准流程

                    
节点接入建议

                  

                

                

                  

                    1. 先录入节点档案
                    统一命名、地域和角色标签，方便后续做站点分配和监控筛选。
                  

                  

                    2. 再部署 node-agent
                    agent 接管 token 刷新、心跳、配置拉取和发布 ACK，避免人工挂单。
                  

                  

                    3. 最后纳入站点绑定
                    上线前先确认节点心跳稳定，再进行站点绑定和版本发布。

安全边界

                    
模板使用建议

                  

                

                

                  

                    优先使用参数白名单
                    把高风险输入收敛成少量参数，避免把任意 shell 暴露给平台操作员。
                  

                  

	                    DNS 切换优先内置能力
	                    节点异常时的解析 IP 切换由 failover-worker 内置处理，不再建议依赖节点动作模板兜底。
                  

                  

                    执行用户需与 agent 对齐
                    当前 `run_as_user` 只做一致性校验，不做 sudo / su 提权切换。
